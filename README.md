# Демо-концепция сайта — Белёвская пастильная мануфактура

Концепт редизайна сайта [pastila1881.com](https://pastila1881.com) — производителя
Белёвской пастилы с 1881 года.

Это **демонстрационный макет**, а не рабочий сайт заказчика:

- ассортимент, фотографии, тексты о традиции, награды и адреса взяты
  с открытого сайта производителя и принадлежат правообладателю;
- разделы собраны как пример структуры и подачи;
- цены и кнопка покупки намеренно отсутствуют — это предмет отдельного решения;
- страница закрыта от индексации (`noindex`).

Как обновить: файлы `index.html`, `assets/css/style.css`, `assets/js/app.js` и
фотографии в `assets/img/`.
